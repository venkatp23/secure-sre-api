The Problem: "How do we ensure a high-performance API remains both reliable (SRE) and secure (Cyber) when integrating AI?"

The Solution: A "Secure-SRE" framework using FastAPI, Gemini AI, and Terraform.

Tech Stack: Python, FastAPI, Docker, Terraform, AWS, Prometheus/Grafana, Gemini API.

Security Features: JWT Auth, Bcrypt hashing, Bandit (SAST), Safety (SCA), and AI-driven anomaly detection.

SRE Features: Multi-stage Docker builds, Gunicorn process management, Prometheus metrics, and IaC (Terraform).
